# 参考实现

参考实现按用途分为六个目录。代码取自实际运行的系统，公开前做了三项处理：将个人路径替换为占位路径；密钥仅以环境变量名出现；删除与本机专有服务绑定的代码。业务逻辑未作修改，技术报告中与这些脚本相关的实测数字可以与代码对照。

| 目录 | 用途 | 与本文基础设施的耦合点 |
|---|---|---|
| `01-ocr-chunking/` | 入库：切块、元数据、写库 | 依赖 MinerU 的产物目录命名（`<书名>/<分册>-<uuid>/full.md`） |
| `02-vectordb-ops/` | 诊断与修复 | 依赖 ChromaDB 1.5.9 的 `embeddings_queue` 表结构 |
| `03-retrieval/` | 检索与取块 | 依赖 DashScope 凭证与 collection 命名 |
| `04-locating/` | 层级索引查询 | 只读，依赖 `toc_index.json` 与 `chunk_loc.json` |
| `05-agent-infra/` | 只读检索 MCP 服务 | 依赖向量库的独立 venv 与 `kb_search.py`、`kb_get_chunk.py` |
| `06-baselines/` | 第 4 节数据表 | 无依赖 |

未全量开源的内容：教材与真题的原始 PDF、OCR 产物、向量库本体涉及版权；`.env` 中的凭证与平台凭据不纳入仓库；每日复习流水线包含个人进度，仅保留结构说明。这些内容不属于本仓库的开源范围。

使用这些代码之前，先阅读对应目录的 README。每个目录都说明了需要修改的位置，以及依赖特定版本的行为。
